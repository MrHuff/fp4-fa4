# SM100 D128 causal GQA backward tuning

Date: 2026-08-14

Device: GPU 0 (GB200)

Geometry unless noted: B=1, Hq=32, Hkv=8, D=128, causal

Timing: warm cache, CuTe event timing

## Retained shape-specific configurations

BF16:

- Q2, dO1, dK/dV2 pipeline stages;
- reduction/compute registers 152/128, MMA/load registers 96/96;
- split query-head ownership;
- BF16 dK/dV partials and vector-4 FP32 merge;
- merge fused into a 256-thread, 32-row dQ conversion launch.

FP8-input/BF16-gradient diagnostic:

- Q2, dO3, dK/dV1 pipeline stages;
- the same register split and partial-gradient format;
- 256-thread fused merge, 32 rows at S512 and 64 rows from S1024 upward.

D128 BF16 cannot use dO2: it allocates 265,216 bytes of shared memory, above
SM100's 232,448-byte limit.  FP8 operands free enough shared memory for dO3;
dO4 and Q3+dO3 both regress.

## Context-length sweep

| Sequence | Serialized BF16 (us) | Retained BF16 (us) | BF16 speedup | Retained FP8 (us) | FP8 vs BF16 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 512 | 93.543 | 62.054 | 1.507x | 60.962 | 1.018x |
| 1024 | 155.750 | 108.909 | 1.430x | 88.725 | 1.227x |
| 2048 | 286.289 | 245.849 | 1.164x | 192.662 | 1.276x |
| 4096 | 783.258 | 651.635 | 1.202x | 496.655 | 1.312x |
| 8192 | 2167.023 | 2025.233 | 1.070x | 1508.557 | 1.342x |

Against the serialized BF16 starting point, the retained FP8 path is 1.534x,
1.755x, 1.486x, 1.577x, and 1.436x faster across the same sequence sweep.
The low-precision crossover strengthens with context length: FP8 is only 1.76%
faster at S512 but 25.51% faster at S8192.

At S4096, serialized FP8 with the same Q2/dO3 staging is 569.508 us, so split
ownership plus fused publication contributes another 1.147x.  The equivalent
Hq=Hkv=32 ceilings are 629.760 us for BF16 and 486.116 us for FP8.  Retained
GQA is therefore only 3.47% and 2.17% above the corresponding MHA paths.

## Measured Llama-8B attention-core aggregate

The repository's causal native-GQA forward artifact was measured independently
at the same B=1, Hq=32, Hkv=8, D=128, S4096 geometry.  Adding the measured
forward and backward kernel times gives the following attention-core aggregate:

| Path | Forward (us) | Backward (us) | F+B aggregate (us) |
| --- | ---: | ---: | ---: |
| Native BF16 | 211.712 | 651.635 | 863.347 |
| NVFP4 QK / MXFP4 PV forward + FP8-input backward | 158.752 | 496.655 | 655.407 |

The low-precision aggregate is **1.317x faster**, reducing measured attention
forward-plus-backward time by **24.09%**.  This is a sum of matched component
measurements, not yet a single chained launch or a full transformer-block
benchmark.  It excludes QKV/projection backward, RoPE, adaptive packing, and
optimizer work.

The aggressive forward diagnostic has output cosine 0.949414 (LSE cosine
0.999985), while the backward timing harness's naive E4M3 input generator has
dV cosine 0.963943.  These timings establish the kernel ceiling, not a
convergence-ready default.  A production end-to-end path must feed both kernels
from the projection-native adaptive-scale and fused-RoPE epilogues, then validate
loss and gradient behavior at model level.

## Profile attribution

Nsight Systems averages at S4096:

| Kernel | D128 fused GQA BF16 (us) | D128 MHA BF16 (us) |
| --- | ---: | ---: |
| Main backward | 568.576 | 558.471 |
| dQ conversion plus GQA merge | 48.480 | 38.523 |
| O*dO / scaled-LSE pass | 28.482 | 28.901 |

The residual BF16 GQA tax is split almost evenly between partial publication in
the main kernel and four-way accumulation in the fused epilogue.  No additional
barrier or TMEM stage is implicated.

## Accuracy boundary

BF16 at S256, Hq=4, Hkv=1:

| Gradient | Relative L2 | Cosine |
| --- | ---: | ---: |
| dQ | 0.002050 | 0.9999979 |
| dK | 0.002505 | 0.9999971 |
| dV | 0.001973 | 0.9999982 |

The timing harness deliberately uses a naive unscaled E4M3 cast.  With that
diagnostic input generator, FP8 gives dQ/dK cosine 0.999865/0.999838 but dV
cosine 0.963943 (relative L2 0.2663).  This is not the proposed training
accuracy path.  Production FP8 must consume projection-native, adaptively
scaled operands so the kernel receives low-precision data without a separate
fake-quantization pass.

## Rejected ceiling experiments

- Packed BF16x2 direct atomics preserve dQ/dK/dV cosine above 0.999995 on the
  small BF16 check, but four-way contention raises S4096 D128 latency to
  739.983 us.
- Packed FP32x2 merge arithmetic measures 652.227 us, within noise/slightly
  behind the ordinary vector accumulation because of added register movement.
- Fused block sizes 128 and 256 regress; 64 is the FP8 long-context optimum.
- Register split 136/136 ties or slightly trails 152/128; more aggressive
  reallocations are invalid at runtime on SM100.

The remaining speed opportunity is no longer in GQA scheduling.  It is in
integrating adaptive low-precision Q/K/V/dO production into projection
epilogues and consuming the completed dQ reduction directly in projection
backward, avoiding standalone materialization and quantization.
